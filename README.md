# DSH 轻量播放器

基于 ArtPlayer 的 DSH / Cordis 内核插件。播放器代码随插件打包，不依赖 CDN，不需要构建 APK。

适配目标为 dsh-Go 仓库快照 `cf8ae43f9b0f070ca7da3a0a126bcc7443f7e163` 所固定的 DSH `0.2.1-rc.4`。插件声明了这一版本约束，未将未测试的内核版本标为兼容。

## 使用

从 DSH 网页侧边栏打开「轻量播放器」。默认是紧凑的横向小窗，双击视频画面铺满当前网页，再双击恢复小窗。触屏支持连续轻点两次。

- 长按播放中的画面，临时切到 3×；松手、取消手势、窗口失焦、切入后台或暂停后恢复原倍速。
- 播放器显示简洁的顶部操作和底部进度条，播放时自动隐藏。
- 在播放器内打开本地视频或 HTTP(S) 视频直链；HLS 使用内置的 hls.js。
- 更多设置放进菜单，避免占用画面。

双击只负责放大与缩小，不再承担快进、快退。页面铺满不调用系统全屏或 Android 方向接口。

## 安装

在目标 DSH 的插件管理页安装 npm 包 `dsh-artplayer`，或在 Creator 会话中使用官方工具：

```json
{
  "action": "install_bundle",
  "target": "dsh-artplayer@1.0.0"
}
```

请在 DSH 内核中安装；普通 `npm install` 仅下载包，不会注册 DSH 插件。

把完整插件目录复制到 **DSH 内核所在的设备**，在该内核的插件管理中安装本地插件目录。路径必须是内核能访问的绝对路径；电脑上的 Windows 路径不能直接作为手机 PRoot 内核路径使用。

也可在目标 DSH 的 Creator 会话中，将实际目录路径交给官方 `plugin_manager`：

```json
{
  "action": "install_bundle",
  "target": "/内核可访问的绝对路径/dsh-artplayer"
}
```

插件包名为 `dsh-artplayer`。安装结果的 `application: applied` 才表示当前内核已经应用；若提示 `restart-required`，按内核提示重启。安装失败应处理其原始错误，不要通过手改配置或忽略版本检查绕过。

安装包不会自行修改你的现有 DSH 配置，需要在目标内核完成安装与启用。

## dsh-Go 中的入口与边界

插件通过官方 `sidebar.panellist` 和 `main` 槽注册。dsh-Go 仓库说明，这类网页插件面板可以从「全部功能 → 插件」进入；具体是否能显示在手机网页岛中，由 dsh-Go 的主机连接方式、网页桥接能力与资源预算决定。

小窗打开时锁定的是其所在网页的背景操作。**纯内核插件没有锁定 Android Activity 方向、冻结 Flutter 原生页面或覆盖整个原生 App 的接口。** 手机左右横转对原生界面的影响，不能由这个插件保证消除。播放器自身的画面旋转不修改系统方向。

这里的「铺满页面」指当前网页或 App 给插件分配的网页区域，不承诺覆盖手机状态栏、原生导航栏或原生聊天界面。

## 媒体支持

实际编解码能力取决于浏览器或手机 WebView。MP4 文件容器并不保证其中每一种音视频编码都能播放。HTTP(S) 链接必须能被当前浏览器访问；跨域限制、登录鉴权、HTTPS 页面访问 HTTP 资源、损坏的媒体会直接显示错误。

HLS 资源服务器需要允许浏览器跨域访问。插件不代理媒体，不绕过站点鉴权，不自动切换到另一播放器掩盖播放失败。本地文件由浏览器读取，不上传到 DSH 服务端。

## 维护

源码位于 `src/`。安装包自带构建后的 `dist/client.js`；普通使用不需要 npm 或编译。开发构建使用锁定的依赖版本：

```sh
npm ci
npm run build
npm test
```

依赖许可见 `THIRD_PARTY_NOTICES.txt` 和 `licenses/`。验证范围、实际通过的检查及未验证项见 [VERIFICATION.md](VERIFICATION.md)。网页视觉、手机触摸操作和 dsh-Go 真机集成尚未完成实测。
